# கரும்பு கணக்கு – Android APK

இந்த folder-ஐ GitHub-ல் upload செய்தால் APK தானாக உருவாகும் (கணினி / Android Studio தேவையில்லை).

1. github.com-ல் புதிய repository உருவாக்கவும் (Private ஆகவும் இருக்கலாம்).
2. இந்த folder-ல் உள்ள அனைத்தையும் (`.github` folder உட்பட) "Add file → Upload files" மூலம் upload செய்து Commit செய்யவும்.
3. மேலே **Actions** tab → "APK உருவாக்கு" → (தானாக ஓடும்; இல்லையெனில் **Run workflow**).
4. சுமார் 3–5 நிமிடம் கழித்து பச்சை ✔ வந்ததும், அந்த run-ஐ திறந்து கீழே **Artifacts → karumbu-kanakku-apk** பதிவிறக்கவும்.
5. Zip-ஐ extract செய்து `app-debug.apk`-ஐ போனில் install செய்யவும் ("Unknown sources" அனுமதி தேவைப்படலாம்).

குறிப்புகள்
- App முழுவதும் offline-ல் இயங்கும். தரவு போனுக்குள் மட்டுமே சேமிக்கப்படும்; app-ஐ uninstall செய்தால் தரவு அழியும் – அவ்வப்போது Excel/backup எடுக்கவும்.
- Excel / PDF பதிவிறக்கங்கள் போனின் Downloads கோப்புறையில் சேமிக்கப்படும்.
- புதிய பதிப்பு வேண்டுமெனில் `app/src/main/assets/index.html`-ஐ மாற்றி commit செய்தால் போதும்; APK மீண்டும் உருவாகும்.
